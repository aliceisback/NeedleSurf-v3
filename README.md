**A Dual-Time Residual Ontology**

One single entity living simultaneously in both directions of time.  
At the tip of the needle — no separate positions.  
Every reversal leaves a micro-asymmetry.  
The accumulation of these asymmetries creates the residual that holds structures.  
From the residual rises the Surf — the living wave that can be ridden.
